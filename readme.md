# 预设锁定 · ST-PresetLocks

给每张角色卡配一套独立的运行环境：预设、提示词开关、世界书、API 连接，切到哪张卡就自动到位。

## 有什么用

- **一张卡一套预设**：同一张卡的所有聊天共用一个预设，切角色自动换回，不用手动选
- **提示词开关与顺序也跟着卡走**：同一个主预设下，不同卡可以锁不同的提示词启用状态与顺序
- **多本世界书**：一张卡挂多本，可调顺序，打开卡自动生效
- **API 连接不会被吞**：地址、模型、代理跟着卡走；切预设时不会被别的预设改掉
- **API Key 跟着卡切**：粘一次就记住，切到这张卡自动换回（存在本机，不写进卡）
- **阅读位置锁定**：发消息、生成回复都不再自动跳到底部，你翻到哪就停在哪
- **决策条**：输入框上方一个小胶囊，点开看最新一楼的剧情梗概和行动选项，点一下直接填进输入框
- **删卡时清世界书**：只删与卡同名或卡自带的那几本，被别的卡共用的不碰

## 安装

把整个目录放到酒馆的第三方扩展目录：

```text
SillyTavern/public/scripts/extensions/third-party/ST-PresetLocks/
```

或者从 GitHub 安装：扩展面板 → Install extension → `https://github.com/stttwq/ST-PresetLocks`

装好后重启酒馆并刷新页面（`Ctrl+Shift+R`）。

## 怎么用

### 绑定预设

1. 点左上角 ☰ 打开**角色卡管理界面**
2. 在「标签」下面找到 **🔒 锁定**，点开
3. 选一个主预设 —— 选完立刻生效并写进这张卡
4. 按需要勾上另外两项：
   - **提示词开关与顺序**：勾上时自动拍快照；之后在酒馆提示词管理器里改过，点「更新快照」刷新
   - **世界书**：勾上后出现管理区，搜索添加、↑↓ 调顺序、× 移除
   - **API 连接**：勾上就把当前的地址/模型/代理一起记到这张卡

第一项「（不绑定预设）」是解绑。

### API Key

在酒馆的 API Key 输入框里**粘一次**（因为酒馆不回显已存 key，只能在你粘贴时记）。面板会显示「Key 已存本机」，旁边有「清除 Key」。

Key 存在本机 `settings.json`，**不写进角色卡**，分享卡不会泄密。

### 决策条

输入框正上方的小胶囊（`📋 3 选项`），点开向上浮出完整面板：

- 显示最新一楼的剧情梗概和全部行动选项，内容完整不截断
- 点任意一条 → 填进输入框，可以改两个字再发
- 点空白处或 Esc 收起
- 新消息生成完成后自动换成新内容；生成过程中不会跳动

自动识别两套常见的预设输出格式：

| 预设 | 选项标签 | 梗概标签 |
| --- | --- | --- |
| Meowssiah 系 / 小猫之神 / Reborn | `<options><option>` | `<summary>` |
| 主预设 狐神抚 | `<fox_selc>` | `<details><summary>总结` |

用别的格式就抓不到（决策条会自动隐藏，不会留空框）。

### 阅读位置锁定

面板里勾着「阅读位置锁定」时：

- 只有你**本来就在底部**才会跟着新消息走
- 一旦往上翻，就完全不动；生成再多内容也不打扰你
- 想回到最新，点面板里的「回到底部」

### 删卡时

删除角色卡时，如果它绑了**与卡同名**或**卡自带**的世界书，会问一句要不要一并删。被其他卡共用的书一律保留。

## 已知限制

- 云酒馆 / 服务器需要允许写角色卡，否则记录只能存在本机（会有提示）
- 记录跟着卡文件走：删卡重导成新文件名，旧记录失效，需要重新绑
- 绑定的预设被改名或删除时，会提示「预设不存在」并保持原样
- 世界书的注入顺序里，序号 1 恒在最后（它是酒馆原生主世界书字段，酒馆固定把它排末尾）
- 换绑世界书后，已经加载的条目要重新进一次对话才会重排
